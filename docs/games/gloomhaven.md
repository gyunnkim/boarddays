# 글룸헤이븐 (Gloomhaven) — Beta / 참조용

이 문서는 향후 지원을 검토하기 위한 참조용 문서다. **현재 구현 대상이 아니다.**
`docs/game-rules.md`, `CLAUDE.md`의 지원 게임 목록에도 아직 포함하지 않는다.

## 게임 slug (가안)

`gloomhaven`

## 왜 다른 카테고리인가

듄: 임페리움, SETI, 테라포밍 마스는 모두:

- 단일 세션 종료 시 점수를 합산해 순위/승패를 정하는 구조

글룸헤이븐은 구조적으로 다르다:

- 캠페인 기반 (여러 세션에 걸친 연속 플레이)
- 시나리오 단위로 성공/실패를 판정 (단순 점수 비교가 아님)
- 협동 게임 — 플레이어 간 승패가 아니라 파티 전체의 시나리오 성공/실패
- 캐릭터의 성장(레벨, 카드 언락, 은퇴)이 세션 간 지속됨
- "점수"의 의미가 세션 내 임시 지표(전투 점수 등)와 캠페인 진행도로 나뉨

즉 기존 matches 테이블의 "1회 매치 = 점수/순위/승패" 모델을 그대로 적용하기 어렵다.
지원하려면 최소한 다음을 먼저 설계해야 한다.

## 설계 시 확인해야 할 질문 (미해결)

- "매치"를 시나리오 1회로 볼지, 캠페인 전체로 볼지
- 승패를 시나리오 성공/실패로 대체할지
- 파티(캠페인) 개념을 matches와 별도 도메인으로 둘지
- 캐릭터 성장 정보를 어디까지 기록할지 (범위 밖일 수 있음)
- 확장팩 개념이 다른 세 게임과 동일하게 적용 가능한지 (글룸헤이븐 확장은 신규 캐릭터/시나리오 추가 성격이 강함)

## 확장팩

아직 목록을 확정하지 않았다. 지원을 시작할 때 사용자에게 확인 후 채운다.
